# Datenschutzerklärung — Print Shop Job Manager

Gültig ab: 19. September 2026

Print Shop Job Manager wird von Worksbien Studios veröffentlicht.

Die App ist für die lokale Nutzung ausgelegt. Auftragsdaten, Produktionsstatus, Importvorschauen, Verlauf und Sicherungen werden auf dem Gerät verarbeitet. Worksbien Studios betreibt für diese Version der App weder ein Kontosystem noch einen Cloud-Dienst. Die App enthält keine Werbung, keine Analysen von Drittanbietern und kein Tracking.

Die App greift nur dann auf Dateien zu, wenn ein Benutzer über die Dateiauswahl des Systems eine CSV-Datei oder eine Sicherung auswählt oder sich für den Export einer CSV-Datei oder einer Sicherung entscheidet. Exportierte Dateien werden ausschließlich an das vom Benutzer ausgewählte Ziel übermittelt. Benutzer sind dafür verantwortlich, exportierte oder geteilte Dateien zu schützen.

Apple verarbeitet Abonnementkäufe und die zugehörigen Transaktionsdaten gemäß den Datenschutzbestimmungen von Apple. Worksbien Studios erhält nur die StoreKit-Berechtigungsdaten, die zur Freischaltung von Pro erforderlich sind. Die App erhält keine vollständigen Zahlungskartendaten.

Wenn die App gelöscht wird, wird auch der auf dem Gerät gespeicherte Arbeitsbereich entfernt, sofern er nicht in einer separaten Gerätesicherung oder einer vom Benutzer exportierten Sicherung enthalten ist. Beispielinhalte können in den Einstellungen entfernt werden.

Bei Fragen zum Datenschutz wenden Sie sich an support@worksbienstudios.com.
