# Conditions d’utilisation — Print Shop Job Manager

Date d’entrée en vigueur : 19 septembre 2026

Print Shop Job Manager est un outil local de suivi de production publié par Worksbien Studios. La version gratuite permet de créer jusqu’à cinq commandes réelles. Un abonnement Pro à renouvellement automatique débloque la création illimitée de nouvelles commandes. Les options mensuelle et annuelle sont affichées au tarif fourni par l’App Store pour la boutique de l’utilisateur. Aucune période d’essai limitée dans le temps n’est proposée. Les commandes existantes, les actions permettant de les finaliser, les sauvegardes et les exports restent utilisables si Pro expire.

Les abonnements se renouvellent automatiquement, sauf s’ils sont résiliés avant leur renouvellement dans les réglages des abonnements du compte Apple.
